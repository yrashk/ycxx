# Generate C++ source for a native host tool

The `scanner_source` action reads `score.txt` and produces `scanner.cc`
and `scanner_score.hh` in the same output directory. The generated source
quotes the sibling header and checks that both outputs agree on the score.

```text
generate "scanner_source" {
    tool = "/bin/sh"
    args = [input("script"), input("score"), output("source"), output("header")]
    inputs = { script = "generate-scanner.sh" score = "score.txt" }
    outputs = { source = "scanner.cc" header = "scanner_score.hh" }
}

cpp.host_executable "scanner" {
    sources = [artifact("scanner_source", "source")]
    generated_headers = [artifact("scanner_source", "header")]
}
```

The `config` action runs the linked scanner on the host and writes
`generated_config.hh` for the selected app target. [Build definition](build.ycxx)

## Build the foreign app first

Run from this directory on x86-64 Linux or arm64 macOS with `ycxx` on
`PATH`.

```sh
example=$(mktemp -d "${TMPDIR:-/tmp}/ycxx-host-generated-sources.XXXXXX")
cp build.ycxx generate-scanner.sh generate-score.sh main.cc score.txt "$example"
cd "$example"

case "$(uname -s):$(uname -m)" in
    Linux:x86_64) alternate=arm64-apple-darwin ;;
    Darwin:arm64) alternate=x86_64-pc-linux-gnu ;;
esac

ycxx build app --target="$alternate" --trace-engine=json 2> foreign.jsonl
file ".ycxx/targets/$alternate/out/app"
ycxx show app --target="$alternate" --format=html > foreign-plan.html

ycxx build app
status=0
.ycxx/out/app || status=$?
printf '%s\n' "$status"
test "$status" -eq 17
```

The foreign app is Mach-O arm64 on a Linux host or ELF x86-64 on a macOS
host. Open `foreign-plan.html` and follow `app`, `config`, and `scanner` in
**Target dependencies**. The scanner card has `sources` and
`generated_headers` edges to the same `scanner_source` card. The edge
links open the two bindings in `build.ycxx`.

## Reuse equal generated bytes

Add surrounding spaces to the score and rebuild the same foreign target.

```sh
printf '%s\n' ' 17 ' > score.txt
ycxx build app --target="$alternate" --trace-engine=json 2> same-source.jsonl
grep -F '"kind":"ExternalAction"' foreign.jsonl same-source.jsonl
```

`scanner_source` runs again, and the source and header are byte-for-byte
equal to the original outputs. The scanner compile and the app's
`config` action can reuse their results.

## Watch a changed source and header

Run watch for the default app.

```sh
ycxx build app --watch --trace-engine=interactive
```

After the initial build, run `printf '%s\n' 23 > score.txt` in another
terminal. Both generated scanner files change, and watch rebuilds the
scanner, runs `config`, and rebuilds the app. Check the new score and
refresh the plan after watch reports success.

```sh
status=0
.ycxx/out/app || status=$?
printf '%s\n' "$status"
test "$status" -eq 23
ycxx show app --format=html > updated-plan.html
```

Press `q` in the trace view to stop watch.
