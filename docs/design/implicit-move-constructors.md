# Implicit move construction of ordinary wrappers

The class completion step shares its implicit declaration decision with the existing special-member classification. The new constructor applies to a namespace-scope class whose implicit copy is deleted and whose implicit move is available and nontrivial. The first native slice uses ordinary scalar and class fields without base subobjects. A user-declared copy, move, assignment or destructor suppresses the implicit move according to [class.copy.ctor].

Class completion builds initializers from the corresponding fields of the source xvalue in declaration order. Class fields use ordinary direct initialization and the enclosing class's access. The initial slice requires the selected field initialization and its exception checks to prove that the generated constructor is nonthrowing. An initializer that cannot be proved usable leaves the existing constructor selection and diagnostics in place. The generated member is public and inline, and its class retains its aggregate classification. [class.copy.ctor], [over.match.ctor], and [except.spec].

The existing member-reference walk requests the prepared definition only when code uses its entity. Emission reuses member initialization and applies the inline coalescing rules to the synthesized symbol. Array, reference and base subobject work and broader exception cases continue in [#244](https://github.com/yrashk/ycxx/issues/244). [#747](https://github.com/yrashk/ycxx/issues/747).
